# TypeSprint – Typing Speed Tester

TypeSprint is an interactive web application that helps users practise typing and measure their typing speed and accuracy.

## Features
- 60-second typing test
- Random typing passages
- Live words-per-minute (WPM) calculation
- Typing accuracy measurement
- Correct and incorrect character highlighting
- Restart functionality
- Responsive sunset-inspired user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Start typing to begin the test.

## Project Structure
- `index.html` – Webpage structure
- `style.css` – Styling and responsive design
- `script.js` – Timer, typing logic, and statistics
